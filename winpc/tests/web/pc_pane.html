Mã đăng ký mới — chỉ hiện 1 lần ở đây (hệ thống không lưu mã gốc). Không gửi mã này cho ai. ISO tạo bằng mã cũ sẽ không đăng ký được máy mới nữa.
Tạo file ISO cài Windows tự động — trên máy tính Windows đang có file ISO Windows gốc, mở Windows PowerShell (Admin) (không dùng CMD), dán nguyên dòng dưới rồi Enter. Lệnh sẽ hỏi đường dẫn ISO và mã đăng ký.
Cảnh báo máy PC về mail / Telegram của admin — hết hạn thuê, sắp hết hạn, máy hết hạn bị bật lại, máy đang thuê mất kết nối, máy lạ đăng ký, đồng hồ / bảo mật / phần cứng trên máy bị đổi, cài lại thất bại. Mọi cảnh báo cũng hiện ở tab 🛡️ Bảo mật.
Đặt 0 phút = tắt loại cảnh báo đó. Mail gửi tới địa chỉ ADMIN_EMAIL đặt trên Vercel (cần thêm RESEND_API_KEY); Telegram dùng bot đang có.
